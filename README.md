# MARVELS Longitudinal Immune Response Analysis

## Overview

This repository contains the R code used for statistical analyses and figure generation in the MARVELS longitudinal immunological study.

The study investigates longitudinal changes in SARS-CoV-2-specific humoral and cellular immune responses in children, the associations of intervening SARS-CoV-2 infection and booster vaccination with subsequent immune responses, and the relationship between baseline immune phenotypes and subsequent infection.
